# 国際標準規格の採用実態 調査プロジェクト

Current Status of International Standard Adoption

分野をまたいで「国際標準がどこまで・なぜ採用されているのか（あるいは採用されないのか）」を、統一した分析フレームで調べ、領域別にカタログ化・分析する調査シリーズ。既存の公的枠組みでは、分野横断で採用実態を一望する見取り図がこぼれ落ちやすい。本プロジェクトはその隙間を埋めることを狙う。

> 版・年号は各レポートの作成時点で確認した公開情報に基づく。断定を避ける箇所は〔要確認〕と付す。

## 分析フレーム（全レポート共通）

### 強制メカニズム類型（M1〜M6）

標準の採用は技術的優位性だけでは決まらず、次のいずれかの「強制メカニズム」が働くときに進む。

| # | メカニズム | 内容 | 強く効く領域 |
|---|-----------|------|-------------|
| M1 | 市場排除 | 従わないと取引・決済網から外れる | 金融決済、通信接続 |
| M2 | 規制・法的義務 | 法律・規則で準拠を義務化 | 化学、医療機器、自動車 |
| M3 | 認証・型式承認（安全） | 認証を通らないと市場・運用に出せない | 航空、自動車、医療機器 |
| M4 | 公共調達・調達要件 | 発注者が準拠を要求 | 軍事、BIM |
| M5 | ネットワーク効果 | 法的強制なしでも参加者増で支配的に | 通信、Web、文字コード |
| M6 | なし（任意） | 自発性に委ねられる | 研究データ、一部産業データ |

### 標準化の地政学（4エンジン）

標準を「作る力」は地域ごとに別エンジンで動く。詳細は[横断コラム](横断コラム_標準化の地政学と日本の立ち位置.md)。

- EU＝ルール（de jure／M2規制）　- 米国＝市場（de facto／M5ネットワーク効果）
- 中国＝国家×量（ITU/IEC/ISOへの票数攻勢）　- 日本＝製品・材料・計測（M3）中心で、ルール／プラットフォーム層は取りにいけていない
